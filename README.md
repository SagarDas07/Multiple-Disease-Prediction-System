# Multiple Disease Prediction System

This repository contains a Streamlit-based web application for predicting multiple diseases using machine learning models. The application provides predictions for the following diseases:

1. **Diabetes**
2. **Heart Disease**
3. **Parkinson's Disease**

---

## **Features**

* User-friendly interface for entering required input values.
* Machine learning models are used for accurate predictions.
* Separate prediction pages for each disease.

---

## **Setup Instructions**

### **1. Prerequisites:**

Ensure you have the following installed on your system:

* Python (>=3.8)
* pip (Python package manager)

### **2. Clone the Repository:**

```bash
git clone https://github.com/SagarDas07/Multiple-Disease-Prediction-System
cd Multiple-Disease-Prediction-System
```

### **3. Create a Virtual Environment:**

```bash
python -m venv new_env
source new_env/bin/activate     # For Linux/Mac
new_env\Scripts\activate       # For Windows
```

### **4. Install Dependencies:**

```bash
pip install -r requirements.txt
```

### **5. Run the Application:**

```bash
streamlit run main.py
```

---

## **Usage Instructions**

1. Run the application using the command mentioned above.
2. Select a disease prediction option from the sidebar.
3. Enter the required inputs in the text fields provided on the selected page.
4. Click the **Test Result** button to get the prediction result.
5. The prediction result will appear below the button.
